# Indexing and AI-training opt-out.
#
# WHAT THIS FILE DOES AND DOES NOT DO
#
# This file is authoritative only when it is served from the ROOT of a host you
# control -- e.g. https://your-pool.example/robots.txt. Crawlers fetch robots.txt
# from the site root and nowhere else.
#
# Sitting in a public GitHub repository, this file has NO technical effect on
# github.com: GitHub serves its own /robots.txt and controls how the repository is
# crawled. A robots.txt committed to a repo does not de-index that repo. The only
# reliable way to keep a repository out of search indexes and scraping corpora is
# to make the repository private. Treat the copy in this repo as a declaration of
# intent, and deploy it at the root of any host that serves this software.
#
# The self-hosted console additionally sends, on every response:
#   X-Robots-Tag: noindex, nofollow, noarchive, nosnippet, noimageindex, noai, noimageai
# (see internal/console/console.go). That header is the stronger control: it travels
# with each response, so it still applies to deep asset URLs fetched directly and to
# non-HTML responses that are never parsed as a document.
#
# Everything below is advisory. Compliance is voluntary. A crawler that chooses to
# ignore robots.txt is not prevented by it -- only by authentication and network
# controls, which is what actually protects this deployment.
