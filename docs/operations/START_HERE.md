# 🚀 从这里开始！

**欢迎使用 Pool Server 生命周期管理系统！**

---

## ⚡ 快速开始（3步）

### 1️⃣ 启动服务

```bash
cd /workspace/pool_server
./pool_server
```

### 2️⃣ 打开浏览器

访问任务管理页面：
```
http://localhost:8787/frontend/registration.html
```

### 3️⃣ 创建第一个任务

在页面上填写：
- 任务类型：仅注册
- 平台：ChatGPT
- 目标数量：5
- 并发数：2
- 点击"🚀 创建任务"

就这么简单！✨
